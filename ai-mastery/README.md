# إتقان الذكاء الاصطناعي — مسار تعلّم تفاعلي

موقع تعليمي من صفحة واحدة، عربي بالكامل وباتجاه RTL، مبني بـ Vite و Tailwind CSS بلا أي مكتبة
واجهة خارجية. ثماني وحدات، كل وحدة تنتهي بتمرين عملي، ومتتبع تقدّم يرافق المتعلّم.

**الرابط بعد النشر:** `https://labs.ialhasan.com/ai-mastery/` (غير مُدرج في فهرس الموقع)

## التشغيل والبناء

```bash
cd ai-mastery
npm install
npm run dev     # خادم تطوير على /ai-mastery/
npm run build   # يبني إلى ../static/ai-mastery
```

## كيف يصل إلى الإنتاج

Netlify يشغّل `hugo` فقط ولا يعرف شيئاً عن Vite. ولهذا:

1. `npm run build` يضع المخرجات في `static/ai-mastery/` (انظر `vite.config.js`).
2. Hugo ينسخ كل ما في `static/` كما هو إلى `public/`.
3. النتيجة تُقدَّم على `/ai-mastery/`.

**مهم:** مخرجات البناء في `static/ai-mastery/` مُتتبَّعة في Git عن قصد. أي تعديل على المصدر
يجب أن يتبعه `npm run build` ثم رفع المصدر والمخرجات معاً، وإلا بقي الموقع المنشور على نسخته
القديمة.

## بنية المصدر

| الملف | الدور |
| --- | --- |
| `index.html` | هيكل الصفحة والنصوص الثابتة لكل وحدة |
| `src/style.css` | نظام التصميم: الألوان، الخط، مكوّنات الواجهة |
| `src/content.js` | كل نصوص التمارين وبياناتها — عدّل المحتوى من هنا |
| `src/store.js` | حالة المتعلّم والتقدّم والحفظ في `localStorage` |
| `src/ui.js` | أدوات بناء العناصر المشتركة |
| `src/modules/m1…m8` | تمرين كل وحدة |
| `src/modules/exports.js` | لوحة المخرجات القابلة للتنزيل |

## نظام التصميم

| الرمز | اللون | الاستخدام | التباين على الأبيض |
| --- | --- | --- | --- |
| `--color-ink` | `#2C4948` | نص الجسم | 9.8:1 |
| `--color-brand` | `#3F6E67` | الأزرار والروابط والعناصر النشطة | 5.8:1 |
| `--color-brand-dark` | `#244C44` | الأشرطة الداكنة (نص أبيض 9.6:1) | — |
| `--color-brand-light` | `#4F9688` | حدود وأيقونات وتعبئة فقط | 3.5:1 |
| `--color-brand-ink` | `#42806F` | بديل آمن للنص مشتق من الفاتح | 4.6:1 |
| `--color-wrong` | `#B4553F` | إشارة الخطأ، مصحوبة دائماً بأيقونة | 4.9:1 |
| `--color-warn` | `#C98A2E` | تعبئة وأيقونات فقط، لا نصوص | 2.9:1 |

اللون الفاتح `#4F9688` لا يحقق معيار WCAG AA للنصوص العادية، ولهذا يقتصر على الحدود
والأيقونات والتعبئة، ويحلّ محله `--color-brand-ink` حين يلزم نص بلون مشتق منه.

الخط: **Tajawal** بأوزان 400 / 500 / 700 / 800 من Google Fonts. الأرقام لاتينية في كل الموقع.

## الخصوصية

لا يوجد أي اتصال بخادم أو واجهة برمجية. تمرين «مُتنبّئ الرموز» محاكاة توضيحية بجدول أنماط
ثابت داخل المتصفح، وليس نموذجاً حقيقياً. كل ما يكتبه المستخدم يبقى في `localStorage` على
جهازه، ويمكنه مسحه بالكامل من زر «إعادة ضبط التقدم» في التذييل.
